# Course builder: before and after

Each file is one screen at one size, main on the left and this branch on the right:

| | |
| --- | --- |
| `title-*` | the title screen — Build a hole is now its third button |
| `setup-*` | the new round screen — Build a hole has gone from it |
| `builder-*` | the builder itself — a bigger board, a step line, nine tools that read at a glance |

Sizes: `desktop-1280x800`, `phone-390x844` (an iPhone 14 upright), `phone-844x390` (the same phone on its side).
Taken from the production build at each size with Playwright (Chromium), fonts settled, reduced motion.
